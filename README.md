# MFPF Cow Hostel Landing Page

Single-page HTML/CSS/JavaScript prototype based on the Milk Farmers Pensioners Foundation Cow Hostel PRD, design document, and recommended Next.js/Supabase/Razorpay stack.

## Files
- `index.html` - page structure/content
- `styles.css` - responsive visual design
- `script.js` - interactions, language toggle, counters, demo forms/modals

## Run locally
Open `index.html` directly in a browser, or serve the folder from a local HTTP server.

## Production migration
This is deliberately framework-free as requested. The design is structured so it can later be migrated into Next.js components, with Supabase for records/auth/storage and Razorpay for payments.

## Important placeholders
Replace demo contact details, stats, cow photos/stories, allocation percentages, legal/registration links, and payment setup before launch. The form currently does not send data to a backend.
